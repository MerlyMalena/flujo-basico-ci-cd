# Evidencias del proceso

Guarda aqui las capturas reales de cada prueba en rojo y en verde. Ejemplo:

- `01-azucar-suficiente-rojo.png`
- `01-azucar-suficiente-verde.png`
- `02-azucar-insuficiente-rojo.png`
- `02-azucar-insuficiente-verde.png`

El script guarda automaticamente la salida real de JUnit en archivos de texto
con fecha y hora. Estos registros complementan las capturas recomendadas por el
profesor; no son capturas de pantalla ni documentan ejecuciones anteriores.

Si una prueba nueva pasa de inmediato, registra ese resultado y explica por que
la implementacion anterior ya la satisface. No alteres codigo correcto para
fabricar un fallo. Cuando refactorices, ejecuta todas las pruebas y conserva
tambien ese resultado.
